# Oxford 3000 ภาษาไทย

เว็บท่องศัพท์ Oxford 3000 (American English) พร้อมคำอ่านและความหมายภาษาไทย ไม่มีหลังบ้าน เปิด `index.html` ได้เลย

## โหมด
- **คำศัพท์** – ค้นหาได้ทั้งอังกฤษ/ไทย กรองระดับ A1–B2 บันทึกคำ ★ และฟังเสียง
- **แฟลชการ์ด** – แตะพลิกดูความหมาย กด "จำได้แล้ว" / "ยังไม่จำ" (คำที่ยังไม่จำจะวนกลับมา)
- **แบบทดสอบ** – 10 ข้อ เลือกความหมายที่ถูกจาก 4 ตัวเลือก
- **เขียนคำ** – ดูคำไทย แล้วพิมพ์คำอังกฤษ มีใบ้ทีละตัวอักษร
- **แต่งประโยค** – แตะเรียงคำให้เป็นประโยคตามคำแปลไทย

ความคืบหน้าเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์

## เพิ่มคำศัพท์
แก้ไฟล์ `data/words.js` ต่อท้ายรายการ `WORDS` รูปแบบ:

```js
["word","n.","A1","คำอ่าน","ความหมาย"],
```

ประโยคสำหรับโหมดแต่งประโยค เพิ่มใน `SENTENCES`:

```js
["I like coffee","ฉันชอบกาแฟ","coffee"],
```

## เอาขึ้นเว็บด้วย GitHub Pages
1. repo ต้องเป็น Public (หรือใช้ GitHub Pro สำหรับ repo แบบ Private)
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/English/`
